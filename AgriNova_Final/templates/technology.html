SMART FARMING STACK

Advanced technology modules

These are educational modules. Real hardware integration requires compatible devices and a secure server connection.

🚁 Agricultural Drones

Use aerial imagery for field scouting, crop coverage observation and mapping workflows. Any real drone operation must follow local rules and trained supervision.

📡 IoT Sensor Network

Soil moisture, temperature, humidity and light sensors can send readings to a gateway and dashboard. This project currently stores manual soil entries.

💦 Smart Irrigation

Combine field observations, weather and soil moisture data to plan irrigation. This website does not control pumps or valves.

🛰️ Remote Sensing

Satellite and aerial imagery can help identify crop variability and prioritise field scouting. Actual imagery services need separate data access.

🧠 AI Crop Insights

AI models can assist with image-based crop issue screening, but outputs need expert verification. No diagnostic AI model is connected in this offline project.

📊 Farm Analytics

Use crop, task and soil histories to organise farm decisions. Your account data is saved in a local SQLite database.
